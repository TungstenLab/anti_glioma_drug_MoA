# Mechanism of action of anti-glioma drugs

Analysis of mode-of-action of cis- and trans-anti-cancer drugs in comparison to auranofin. Repo includes code for raw data processing until differential expression analysis.

Raw data and detailed information about data processing can be found at: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE353960

The one-liner ``run_pipeline.sh`` documents the usage of the preprocessing pipeline documented in: https://github.com/MaikTungsten/RNAseq_pipeline

If using this pipeline, make sure you adjust all necessary paths and prepare installations required.
